# Bill of Materials (BOM) - Custom Hackpad

This document lists the maximum parts included in the official Hackpad kit, your grants, and required assembly tools.

## 📦 Official Hackpad Kit Components

| Component | Description / Model | Total Kit Quantity | Notes |
| :--- | :--- | :---: | :--- |
| **Microcontroller** | Unsoldered Seeed XIAO RP2040 | 1 | Core microcontroller |
| **Matrix Diodes** | Through-hole 1N4148 Diodes | 20 | Prevents key ghosting |
| **Key Switches** | MX-Style Mechanical Switches | 16 | Switch grid & spares |
| **Rotary Encoders** | EC11 Rotary Encoders | 2 | Input dials & spares |
| **Display** | 0.91-inch I2C OLED (`GND-VCC-SCL-SDA`) | 1 | Status display screen |
| **Keycaps** | White blank DSA Keycaps | 16 | Key tops & spares |
| **Addressable LEDs** | SK6812 MINI-E LEDs | 20 | Backlighting & underglow |
| **Hardware Screws** | M3x16mm Screws | 6 | Case assembly hardware |
| **Heatset Inserts** | M3x5mx4mm Heatset Inserts | 6 | Threaded case inserts |

## 💰 Grants & Sponsorship

| Grant / Item | Allocation | Description |
| :--- | :---: | :--- |
| **Soldering Iron Grant** | $18 | For purchasing a soldering iron and supplies |
| **PCB & Case Grant** | $15 + Case | For PCB manufacturing and a 3D-printed case via Printing Legion |

## 🛠️ Assembly Tools & Equipment

| Tool | Purpose | Notes |
| :--- | :--- | :--- |
| **Soldering Iron** | Joining components to the PCB | Recommended set to ~350°C |
| **Solder Wire** | Electrical connections | Lead-free rosin-core solder |
| **Flush Cutters** | Trimming diode and switch pins | Precision wire cutters |
| **Tweezers** | Placing SMD LEDs and diodes | Fine-tip anti-static tweezers |
| **Soldering Iron Stand** | Safety and holding the iron | Essential workspace tool |
